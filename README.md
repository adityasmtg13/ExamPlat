# AI Exam Preparation Platform

An AI-powered exam preparation platform built using the MERN stack.

## 🚀 Features

- Student Registration
- Student Login
- JWT Authentication
- Protected Routes
- Responsive UI
- MongoDB Atlas Integration

## 🛠️ Tech Stack

- React + Vite
- Tailwind CSS
- Node.js
- Express.js
- MongoDB Atlas
- JWT
- bcrypt

## 📂 Project Structure

```
ExamPlatform
│
├── client
└── server
```

## ⚙️ Installation

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
npm run dev
```
